# Ravrent Mechanic — October 14, 2026 feature set

Repository: `shepgleis-create/ravrent-mechanic`, existing `main` branch and Vercel project `ravrent-mechanic`.

## Completed in this set

### 1. Garage-linked service planner — available free, stored locally
Location: `/health-center.html`.

- Reads actual vehicles already saved in My Garage (`ravrent-mechanic-v2`) and shows each vehicle's entered mileage.
- Owner may record a more recent odometer reading for scheduling without silently editing Garage data.
- User-defined due mileage/date and repeat interval by miles/months; deliberately **no automatic or fabricated manufacturer service schedules**.
- Due now (entered mileage or date reached), due soon (within 500 miles or 30 days), scheduled, completed counts.
- Record actual completed service date, mileage and cost. Repeating plans advance from the actual entry, with calendar end-of-month clamping (Jan 31 to Feb 28/29).
- Record actual service completions in the existing Ownership Toolkit history and update the Health Center screen immediately.
- Export JSON plan backup, restore unique plans without overwriting saved plans or odometer readings, and export date-based calendar (.ics) reminders.
- A service-plan AI review button prepares a prompt for confirmation in the main chat. **No automatic billable AI request.**
- Browser-storage only. No background push notifications, cloud sync, verified service events or paid entitlements.

### 2. AI efficiency improvements
- Groq fast text model defaults to `openai/gpt-oss-20b` (an open-weight model *hosted by Groq*, **not** OpenAI API billing). Lower per-token costs and higher text output speed than using Qwen 27B for every chat.
- Vehicle photos and sampled video frames still route to `qwen/qwen3.8-27b`, because the text model does not accept images.
- Provider model IDs remain operator-configurable with `GROQ_TEXT_MODEL` and `GROQ_VISION_MODEL`; set `GROQ_TEXT_MODEL=qwen/qwen3.8-27b` if Groq-hosted Qwen is preferred for both.
- Cheap text requests include `reasoning_effort=low` and `include_reasoning=false`. Deep requests use `medium` effort. Distinct Qwen reasoning settings are preserved.
- Existing short conversation history, provider retry-after cooldown, scoped error messages, and local-video-frame upload protections remain.
- **No increased Groq organization quota is promised.** Free limits still depend on the Groq account. A second inference provider requires separate credentials, and optional paid fallback must be explicitly activated.
- Distributed per-network anonymous usage enforcement only activates after proper Upstash Redis and HMAC secret configuration. This is not a paid entitlement system or resistant to network identity changes.

### 3. AI workflow integration
- Existing Repair Case AI handoff from Vehicle Health Center is supported in main chat.
- New individual maintenance-plan review uses the same handoff.
- VIN and Workshop Estimate AI reviews remain editable before the user taps Send, never auto-sending personal/customer information.

### 4. Premium value without fake billing
- Free plan now lists mileage/date service planning and local calendar exports.
- The proposed Workshop Elite tier roadmap remains a plan, **not** a paywall or active subscription. Stripe payments and entitlements are not enabled for this app.

## Production access and next release blockers

Only `GROQ_API_KEY` was visible by **name** in Vercel's environment-variable listing during this work. There are no connected Together, Upstash Redis or billing credentials. Key values were never accessed or printed.

For a large public Free plan, prioritize account authentication, a transactional distributed usage store, provider-level budgets, and measured AI cost per active user *before* enabling unlimited free chat or real subscriptions. Vehicle history and VIN-specific recall completion require authoritative licensed or official verification sources; none should be inferred from model-level NHTSA data.
